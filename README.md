# Ex machine

Presentación interactiva sobre la dependencia de las personas con la inteligencia artificial.

## Publicar en GitHub Pages

1. Sube todos los archivos de esta carpeta a la raíz de un repositorio de GitHub.
2. Abre **Settings → Pages** en el repositorio.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda.
4. Cuando termine la publicación, abre el enlace de GitHub Pages.

Mantén los tres videos junto a `index.html`; la página los carga desde esa misma carpeta.
